# Project instructions

Never use the em dash character. Keep updates factual and concise.

This is a standalone public technical presales demonstrator. All seeded customers, rates, timings and capability ratings are fictional planning assumptions. Never present them as customer outcomes, vendor prices, verified capacity, a binding quotation or regulatory certification.

Hard constraints must take precedence over weighted scores. Conflicting requirements must produce no recommendation. Preserve authored proposal sections when discovery changes, flag stale edits, and label all exports as drafts. Browser drafts must remain on the visitor's device.

Before publication run type checking, meaningful domain/export tests, the build artifact check, real browser checks and public hosting smoke checks. Preserve measured reports and failed evidence. Do not begin project 4 until project 3 is completed.
